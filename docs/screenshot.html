企微 / 公众号 AI 客服

把大模型接到微信客服、企业微信自建应用、微信公众号这几个官方通道，客户或同事发消息，由大模型按你设定的人设回答。

怎么用

  1. 准备装好 Docker、有公网地址的服务器，下载 docker-compose.yml 和 .env.example 并改名为 .env
  2. 在 .env 里填大模型接口、客服人设 CHARACTER_DESC、接入通道及其凭证
  3. 运行 docker compose up -d，放行对应通道端口（微信客服 9888、企微自建应用 9898、公众号 8080）
  4. 到对应后台保存回调地址；企业微信类通道还需把服务器出口 IP 加入「企业可信 IP」
交付形式　Docker 部署（docker-compose.yml + .env），命令行；默认关闭 Agent 模式
